# 社内ダッシュボード 利用ガイド

## 1. このダッシュボードについて

本ダッシュボードは、社内で利用している各種業務アプリケーションを
一元的に利用できる「社内共通の入口」です。

会議室予約、出張管理、車両予約、生産工程表、社長予定など、
日常的に使うシステムへ迷わずアクセスできることを目的としています。

---

## 2. 使い方

### 2.1 ダッシュボードを開く
- 社内ポータル（Googleサイト）から「事務所ダッシュボード」をクリック
- またはブックマークから直接アクセス

### 2.2 アプリを開く
- 各ボタンをクリックすると、該当アプリが **別タブ** で開きます
- ダッシュボードはそのまま残るため、複数アプリを行き来できます

### 2.3 元の画面に戻る
- 各アプリ画面上部の
  「← ダッシュボードへ」または「🏠 社内ポータルへ」から戻れます

---

## 3. ボタンの意味

| 表示 | 説明 |
|----|----|
| 会議室予約 | 会議室の予約・空き状況確認 |
| 出張看板 | 社員の出張・外出状況確認 |
| 車両予約 | 社用車の予約管理 |
| 生産工程表 | 生産工程・進捗の確認 |
| 社長予定 | 社長のスケジュール確認 |

※ 表示内容は業務改善に応じて随時更新されます。

---

## 4. よくある質問

### Q. ボタンが表示されない
- 一時的にメンテナンス中の可能性があります
- 時間をおいて再度確認してください

### Q. リンク先が開かない
- 社内ネットワーク・Googleアカウントでログインしているか確認してください
